# Module 3: User Dashboard & Analytics

The user dashboard serves as the central hub for the Helix experience. It moves beyond simple data display towards "Visual Intelligence"—a dynamic interface where users can interact with their health data to uncover meaningful insights.

## Key Elements

| Dashboard Element | Helix Application Requirement |
| :--- | :--- |
| **Customizable Widgets** | Users can create and arrange widgets for metrics like mood trends, activity levels, and sleep quality. |
| **Data Visualization** | Intuitive charts (line, bar, pie) and a "Continue where you left off" panel for seamless re-engagement. |
| **Drill-Down Capabilities** | Clickable high-level data points to reveal underlying details and contributing factors. |
| **Goal Tracking** | Visualization of progress toward self-defined wellbeing objectives. |

## Visual Intelligence (FitnessOS)

The dashboard tracks both controlled inputs and desired outputs, creating a clear feedback loop.

| Dashboard View | Primary KPIs | Data Source |
| :--- | :--- | :--- |
| **Input Adherence** | Calories, Protein, Training, Sleep | Manual logs, API integrations (Oura, Whoop). |
| **Output Progress** | Weight Trend, Measurements, Photos | Manual entry, smart scales, AI photo analysis. |
| **Health Optimization** | Cardio Minutes, Fiber Intake | User logs, wearable APIs. |

## Conversational Insight Discovery

Powered by an "Insight Finder" AI agent, users can query their data using natural language:

* *"Show me my weight trend for the weeks I hit my protein goal versus the weeks I didn't."*
* *"Is there a correlation between my reported sleep quality and my training performance?"*
