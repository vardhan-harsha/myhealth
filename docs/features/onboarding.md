# Module 1: AI-Driven User Onboarding

The onboarding process represents the first and most critical impression a user has of the Helix platform. Its primary strategic goal is to dramatically reduce the user's time-to-value by making users feel welcomed, supported, and connected from their very first interaction. A successful onboarding experience accelerates satisfaction, and strengthens long-term retention.

## Primary KPIs

* Time-to-Value (TTV)
* Day 7 retention
* Feature adoption rate

## Features

### 1. Welcome & Goal Setting

* The initial interaction will feature a warm welcome message, modeled after Vowel's approach, that immediately communicates the platform's core value proposition.
* Following the welcome, a conversational AI interface, similar to Cleo's, will engage the user with casual, relatable questions to understand their primary wellbeing goals (e.g., manage stress, improve fitness, increase focus), establishing a supportive and personalized tone.

### 2. AI-Powered Personalization

* The AI will analyze initial user inputs, such as job title, stated goals, and potential skill gaps, to craft a bespoke onboarding journey. This includes personalizing content modules and learning paths to cater to the unique needs of every user.
* Inspired by Olvy's quick action list, the system will generate a short, prioritized list of relevant tasks for the user to complete. This provides immediate, tangible actions that help the user experience the app's value without delay.

### 3. Contextual Guidance

* The system will use tooltips, similar to those employed by Webflow, to contextually direct users to key features on their dashboard that align with their stated goals.
* A 24/7 AI-powered chatbot will be available to answer routine questions and provide context-aware tips during the critical first sessions, preventing early churn by ensuring accessible guidance is always available.

## Core Philosophy Integration (FitnessOS)

The intake process begins by gathering primary data points (e.g., body weight, activity level). The AI engine establishes core foundational targets:

* **Calorie Target**: Maintenance calories minus deficit.
* **Protein Target**: 1.6g per kilogram of bodyweight.
* **Training Foundation**: 3-5 days per week of strength training.

Completion generates a "Day 1 Digest" explaining the scientific "why" behind each number, reinforcing the principle of "Controlling the Controllables."
